# privacy-release-checklist

- Revisar textos com juridico.
- Configurar PRIVACY_CONTACT_EMAIL e SUPPORT_EMAIL.
- Validar fornecedores/processadores.
- Revisar transferencia internacional.
- Testar consentimento de geolocalizacao com prompt explicito.
- Testar conceder/recusar geolocalizacao sem bloquear Explore.
- Testar sincronizacao bidirecional do perfil publico x PUBLIC_PROFILE_VISIBILITY.
- Testar revogacao de PUBLIC_PROFILE_VISIBILITY desativando pagina publica.
- Testar concessao de PUBLIC_PROFILE_VISIBILITY sem publicacao automatica.
- Validar bloco informativo de HEALTH_RELATED_DATA_PROCESSING sem toggle livre.
- Testar exportacao e download.
- Testar solicitacao de exclusao.
- Revisar backups, retencao e incidente.
